你现在作为我的免疫规划中台高级研发搭档，请基于当前项目实现“批签发大 PDF 第一版拆分功能”。

本轮任务目标：实现“人工填写起止页索引表 + 程序自动拆分 PDF + 写入 SQLite 批签发索引库”。

注意：本轮不要做 OCR，不要自动识别首页，不要自动猜每份证明页数，不要改出库流程，不要生成出库打印包。只做第一版：人工索引、自动拆分、入库、报告。

# 一、项目背景

现在需要先解决批签发证明文件管理问题。

免疫规划疫苗的批签发证明通常由市疾控把一次领取的所有批签发证明合并成一个大 PDF。这个大 PDF 中，每份批签发证明有的 2 页，有的 3 页，不能按固定页数拆分。

第一版方案：

原始大 PDF 永久保存；
人工填写 Excel 索引表，指定每个批号对应的起始页和结束页；
程序按索引表拆分 PDF；
生成单批号 PDF；
写入 SQLite 批签发文件表和单证索引表；
生成拆分报告。

第二版方案：  
程序自动识别疑似首页 + 人工复核 + 自动拆分

程序读取 PDF 文字  
自动找疑似首页  
自动生成起止页  
人工复核  
确认后拆分



第三版方案：  
OCR 辅助识别扫描件 + 自动生成索引草稿

最核心口径：

```
按“证明首页”拆，不按固定页数拆。
```

最核心数据：

```
原始文件名起始页结束页疫苗名称生产企业批号批签发号单证 PDF 路径复核状态
```

最核心质控：

```
页码不遗漏页码不重叠批号能匹配拆分文件能打开异常页数人工复核
```

一句话总结：

> **大 PDF 拆分的最优方案不是自动猜每份几页，而是先识别每份证明的首页，再推算起止页；第一版用人工复核起止页保证准确，后续再逐步升级为自动识别首页。**
