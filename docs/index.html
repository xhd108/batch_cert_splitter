常见问题

FAQ

需要联网才能使用吗？
默认开启二维码模式，会联网访问国家药监局网站获取批签发信息（仅查询公开数据，无需账号）。 若在政务专网等无互联网环境下使用，勾选"离线模式"即可切换为纯 OCR，全程不联网。
为什么部分页面无法识别二维码？
主要有两种情况：①扫描噪声过高（手机拍摄纸张纹理被误识为黑点），导致 QR 定位图案无法检出； ②证明边框线与二维码角落定位图案粘连，破坏了图案结构。遇到这类情况程序会自动切换 OCR， 识别到的批号以颜色标注置信度，建议人工核查黄色和红色行。
数据存在哪里？会上传到云端吗？
所有数据（PDF、拆分结果、历史记录数据库）均保存在本机，程序不向任何第三方服务器上传文件。 二维码模式下仅向国家药监局公开查询接口发送 URL 请求，不包含任何文件内容。
Windows 安装后提示"Windows 已保护你的电脑"？
这是 Windows SmartScreen 对未签名应用的默认提示，非病毒。 点击"更多信息"→"仍要运行"即可。您也可以在 GitHub Releases 页面核对 SHA256 校验值以确认文件完整性。
支持哪些 PDF 类型？
支持文字层 PDF 和扫描版 PDF（图像 PDF）。扫描版会自动启用 OCR；文字层 PDF 直接提取文本， 速度更快。多份证明合并在一个 PDF 中的场景（市级疾控常见下发格式）是本工具的主要使用场景。
如何反馈问题或建议？
请在 GitHub Issues 提交，附上操作系统版本、问题描述和（如有）截图。处理批号相关的识别错误时，提供脱敏后的 PDF 片段有助于快速定位原因。
